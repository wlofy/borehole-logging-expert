# Field shorthand and glossary

Meanings vary by firm; when a code is ambiguous, keep it as written and ask
(`08` §6). Grouped by topic.

## Description shorthand

| Written | Meaning |
| --- | --- |
| S.A.A., SAA, "same as above", ditto marks, ↓, "see above" | Same material as the previous layer or run |
| w/ | with |
| tr, tr. | trace |
| sm, so | some |
| & | and |
| bl., below | layer starts below this depth ("bl. 4 ft") |
| HP / MP / LP / NP (np) | high / medium / low / non-plastic |
| fg, f.g., f-g | fine-grained |
| mg, cg, c.g. | medium / coarse-grained |
| fg-cg | fine to coarse grained |
| CO SAND | coarse sand |
| d., dk | dark |
| lt | light |
| br, brn | brown |
| gy, gr | grey (watch: "gr" can also mean gravel) |
| mot., mottled | mottled colours |
| ox., oxid. | oxidised / oxidation staining |
| org. | organics |
| rts, rootlets | roots |
| ↑ / ↓ | increase / decrease in (e.g. "↑ silt") |
| ~, approx. | approximately |
| TS | topsoil |
| FILL, MG | fill / made ground |
